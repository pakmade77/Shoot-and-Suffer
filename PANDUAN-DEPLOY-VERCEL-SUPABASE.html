Buat Database di Supabase (Gratis)

Supabase menyediakan database PostgreSQL cloud berkecepatan tinggi gratis.

  1. Buka supabase.com dan login menggunakan akun GitHub kamu.
  2. Klik tombol "New Project".
  3. Isi formulir:
    • Name: shoot-and-suffer
    • Database Password: Buat password kuat (misal: ShootSuffer2026!) (Simpan di Notepad!)
    • Region: Pilih Southeast Asia (Singapore)
  4. Klik "Create new project" dan tunggu 1 menit hingga aktif.
  5. Ambil Connection String:
    • Klik menu Project Settings (⚙️) di kiri bawah > Database.
    • Scroll ke bagian Connection string > pilih tab URI.
    • Di dropdown mode:
      • Transaction (Port 6543) → Salin sebagai DATABASE_URL
      • Session (Port 5432) → Salin sebagai DIRECT_URL
⚠️
Penting: Di dalam connection string yang disalin, ganti tulisan [PASSWORD] dengan password database yang kamu buat di langkah 3.
Buka Supabase Dashboard →
2

Upload Kode ke GitHub

Semua kode, logika sudden death, dan foto profil akan disimpan di GitHub.

  1. Buka github.com/new dan buat repository baru.
  2. Beri nama: shoot-and-suffer (boleh pilih Public atau Private).
  3. Biarkan pilihan lain kosong > klik "Create repository".
  4. Buka PowerShell di komputer kamu, lalu jalankan perintah berikut:
PowerShell Command 
git branch -M main
git remote add origin https://github.com/USERNAME_KAMU/shoot-and-suffer.git
git push -u origin main

* Ganti USERNAME_KAMU dengan username akun GitHub kamu.

Buat Repository di GitHub →
3

Deploy ke Vercel (Hosting Gratis)

Vercel akan mem-build dan memberikan domain publik untuk game kamu.

  1. Buka vercel.com dan login dengan akun GitHub.
  2. Klik "Add New..." > "Project".
  3. Pilih repository shoot-and-suffer > klik "Import".
  4. Buka menu "Environment Variables" dan tambahkan 2 variabel dari Supabase:
    • Key: DATABASE_URL → Value: (Paste connection string port 6543)
    • Key: DIRECT_URL → Value: (Paste connection string port 5432)
  5. Klik tombol biru "Deploy"!
  6. Tunggu sekitar 1 menit hingga selesai. Web kamu sekarang LIVE dengan domain (contoh: https://shoot-and-suffer.vercel.app).
Buka Vercel Deployment →
4

Inisialisasi 9 Pemain di Web Baru

Langkah terakhir untuk memasukkan tabel & foto pemain ke database baru.

  1. Buka link website Vercel yang sudah jadi di browser HP / Laptop.
  2. Masuk ke menu ⚙️ Settings (atau buka https://DOMAIN-KAMU.vercel.app/settings).
  3. Di bagian Data & Reset, klik tombol merah "Reset Demo Data" > "Yes, Reset Data".
